# Dashboard Adaptation Note

## Audience

Briefing Group

## Dashboard Question

How has the average Body Mass Index (BMI) changed among adults aged 20–80 across different NHANES survey cycles within a selected income group?

## Control And Visualization

- Control or interaction: The selected_income variable allows users to select an income category, such as Low Income, Middle Income, or High Income, before re-rendering the dashboard.

- Visualization affected:
- What changes when the control changes:

 Changing the selected income group updates the line graph displaying mean BMI across NHANES survey cycles, along with the corresponding summary table. This allows the briefing group to examine descriptive BMI trends for different income categories.
